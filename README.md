# 박지수 작업 포트폴리오

## GitHub Pages 업로드

ZIP 압축을 풀고 내용 전체(index.html, profile.html, assets, demos, downloads 등)를 저장소 최상위에 업로드하세요. ZIP 자체나 상위 폴더는 업로드하지 않습니다. Pages 설정은 Deploy from a branch / main / (root)입니다. 기존 저장소도 파일 전체 교체 후 Commit changes를 눌러 배포합니다. npm 설치나 빌드가 필요하지 않습니다.

## 최신 변경 사항

- YEON: 싱그러운 그린·따뜻한 베이지·자연스러운 차 색감으로 변경. 메인 미리보기도 같은 색상 적용.
- 이력카드 제목을 간결하게 변경. 계산 설명과 총 경력의 괄호 문구 삭제.
- 이력카드와 Word에서 개인 프로젝트 섹션 삭제. 포트폴리오 메인의 산출물은 유지.
- 최신 실무 경력: 2025.08 ~ 현재.
- 총 경력은 한국 시간의 현재 월까지 자동 합산. 2026.10.15 기준 11년 9개월.
- 시작·종료월 포함, 중복 월 제거. 원문에서 기간 확인이 필요한 나머지 4건은 계산 제외.
- 페이지 접속, 날짜 변경 감지, 탭 복귀, 인쇄, Word 생성 시 재계산. 열린 화면은 1분마다 날짜 변경을 확인.
- 이메일 beans87@naver.com, 근무 형태 프리랜서 중심 · 기타 형태 협의 가능 유지.
- 블루 포트폴리오 및 게임형 룰렛·카드 유지.

경력 추가 방법은 EDIT-CAREER.md에 있습니다. profile.html의 경력 표에 행을 추가해도 합계가 자동 갱신됩니다. 인쇄와 이력카드의 Word 버튼은 현재 표를 사용합니다.

## 확인 범위

빌드 및 DOM 기반 주요 기능 검사 통과. 신규 경력 추가, 중복 기간, 월 경계와 한국 시간 적용을 확인했습니다. 기본 문서와 화면에서 생성하는 Word 모델이 동일한 6페이지로 렌더링되는지 검사하고 표 배치를 확인했습니다. 실제 브라우저의 시각적 배치, 애니메이션, 인쇄 미리보기는 미실시입니다.

데모는 가상 데이터이며 새로고침 시 초기화됩니다. 실제 경품·구매·결제·이메일 전송·영구 저장은 없습니다. 외부 CDN을 사용하지 않습니다.
