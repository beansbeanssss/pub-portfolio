# 박지수 UI 퍼블리싱 포트폴리오

## GitHub Pages 업로드

1. 이 ZIP의 압축을 풉니다.
2. 폴더 안의 내용 전체(index.html, profile.html, assets, demos, downloads 등)를 저장소 최상위에 업로드합니다.
3. 저장소 Code 첫 화면에서 index.html이 바로 보여야 합니다. ZIP 자체나 상위 폴더를 올리지 마세요.
4. Settings > Pages > Deploy from a branch > main > / (root) > Save.
5. 배포 후 Visit site를 누릅니다. 기존 사이트는 파일 전체를 교체한 뒤 Commit changes를 누르면 됩니다.

이 파일은 업로드 전용 빌드 결과입니다. npm 설치나 빌드가 필요하지 않습니다. assets와 downloads도 반드시 함께 업로드하세요. 새 화면이 바로 반영되지 않으면 배포 완료를 확인하고 Ctrl+Shift+R로 새로고침하세요.

## 이번 구성

차분한 블루·화이트·그레이 색상으로 정리하고 첫 화면에 작업 탭과 산출물을 배치했습니다. 큰 소개 문구는 하단으로 이동했고 기존 연락 제안 섹션은 삭제했습니다.

- 웹표준: 별도 HTML 서비스 운영 UI. 검색, 상태 필터, 빈 결과, 상세, 업무 요청 등록·검증.
- Vue.js: FLOW 물류 대시보드. 차트, 검색, 센터 필터, 정렬, 페이지네이션, 상세.
- React: ORDERS 주문·발주 관리. 조회, 상태 변경, 품목 추가·삭제, 등록 검증, 합계 계산.
- 인터랙티브 UI: 룰렛, 카드 선택, 미션·보상, 드래그·순서 변경의 산출물 4개. 각 데모 링크는 해당 체험을 바로 엽니다.
- 반응형 웹: YEON 브랜드 웹. 화면 폭 대응, 제품 필터·상세, FAQ, 이메일 입력 검증.

탭은 마우스 클릭 및 방향키·Home·End로 이동할 수 있습니다. 카드의 미리보기는 구현 내용을 요약한 HTML/CSS 도식이며 실제 화면은 데모 보기로 확인합니다.

## 이력카드

profile.html에 실제 경력 37건과 학력·자격·교육을 반영했습니다. 인쇄 / PDF 저장 및 편집 가능한 Word 다운로드를 유지했습니다. 생년월일·성별·주소·병역은 제외했습니다. 이메일·전화번호·합산 총 경력은 미기재입니다. 경력 기간 확인이 필요한 5건은 이력카드 상단 접이식 안내를 검토하세요.

## 검증과 범위

프로덕션 빌드와 DOM 환경에서 탭, 키보드 이동, 웹표준 등록·검색·상세, Vue/React/인터랙션/브랜드 기능, 이력카드 인쇄 호출 및 Word 링크를 확인했습니다. 내부 페이지·자산 경로 51개를 검사했습니다. Word 파일은 기존 검수본을 그대로 유지합니다. 실제 브라우저 시각 검수와 인쇄 미리보기는 미실시입니다.

데이터는 시연용이며 새로고침하면 초기화됩니다. 실제 주문·결제·경품 지급·이메일 발송은 없습니다. 외부 CDN은 사용하지 않습니다.
